## 原件取得情况与复核规则

报告按每条主张标明证据类别，不能把“找到书目”当作“原文支持该句”。本次没有把摘要单独作为充分证据；Glimm–Jaffe 有一项只核到原书选定页，其相关续页仍待核；一个私有伴随材料未取得，因此只记录为项目自述；对特定公开版本未搜到某声明的情况，结论限定为有界的否定证据。源码证据均锚定到固定仓库版本和具体行号。

建议作者按 CSV 的“作者复核结论”“作者备注”两栏逐条确认，重点检查原文上下文是否改变语义、引文是否准确承载当前句子，以及建议英文改句是否符合作者原意。
