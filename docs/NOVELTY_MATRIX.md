## Provisional gap
A typed, physics-specific account of how warrant moves (or fails to move) from formal theorem to model-internal result, target-world claim, and explanatory claim. This is an integration and extension, not an invention of individual components.

## Falsification test
Novelty fails if prior work already integrates: (1) formal theorem validity and scientific statement correspondence; (2) interpretation of formal structures as a physical model; (3) purpose-sensitive model-to-target relation; and (4) an account of how these warrants combine for physical knowledge claims. Search this integrated target before freezing novelty.
