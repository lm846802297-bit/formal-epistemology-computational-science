# Philosophy Papers

Research manuscripts and supporting materials in philosophy of science and philosophy of technology.

## Papers

| Paper | Research question | Where to start |
| --- | --- | --- |
| **Machine-Checked Proofs and Formalization Interfaces in Mathematical Physics: The Epistemology of Osterwalder–Schrader Reconstruction** | When can a theorem checked in one formalization support an inference in another? | [Project guide](docs/OS_PROJECT_GUIDE.md) · [Exact submitted source](https://github.com/lm846802297-bit/philosophy-papers/blob/7101c7685b147d7b6e9e067fae851b41d35bd94c/submission/anonymous-manuscript.tex) |
| **In Lean We Trust? The Ideology of Machine-Checked Proofs in Science** | How does a bounded technical verification come to stand for a broader mathematical achievement in public accounts? | [Public research archive](https://github.com/lm846802297-bit/philosophy-papers/tree/research/proof-assistant-authority-init/projects/proof-assistant-authority) |

The first paper examines what a checked proof warrants across formalizations. The second examines how public accounts attribute mathematical authority and credit. They are separate manuscripts.

## How the repository is organized

- `main` holds this index and the Osterwalder–Schrader project files in their original directories.
- `research/proof-assistant-authority-init` holds the public working materials for *In Lean We Trust?*: drafts, case notes, and an evidence register. These are archival materials, not a record of the version sent to a journal.
- Use a commit-pinned link when citing an exact version. A branch can change over time.
