# From Checking Proofs to Settling Claims
## The authority of proof assistants in science

**Status:** initialized; deferred until the current EJPS manuscript is finished. No data have been collected, and no claims about users' beliefs or motives have been established.

**Research question:** When does public communication about a proof assistant shift from reporting a local verification to presenting a wider scientific claim as settled?

**Relation to the EJPS paper:** The EJPS manuscript supplies a normative baseline for how a checked result can legitimately support a further claim. This project studies how the scope of verification is represented in public discourse. It does not revise the EJPS manuscript or treat its schematic countermodel as behavioral evidence.
